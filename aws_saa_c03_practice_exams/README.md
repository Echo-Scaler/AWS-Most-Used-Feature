## 📝 Exam Tips (စာမေးပွဲ အကြံပြုချက်)

> [!IMPORTANT]
> **Key words to watch for (သတိပြုရမည့် Keywords):**
> - **"most cost-effective"** → Reserved Instance / Spot Instance / S3 lifecycle
> - **"highly available"** → Multi-AZ / Auto Scaling / ELB
> - **"least operational overhead"** → Managed Services (RDS, ECS Fargate, Lambda)
> - **"most secure"** → Least privilege / Encryption / VPC endpoints
> - **"lowest latency"** → CloudFront / ElastiCache / Placement Group

> [!TIP]
> **Elimination Strategy (ဖယ်ထုတ်နည်းဗျူဟာ):**
> မေးခွန်းတစ်ခုတွင် ရွေးချယ်ခွင့် ၄ ခုရှိလျှင် ရှင်းရှင်းလင်းလင်း မမှန်သော ၂ ခုကို ဦးစွာ ဖယ်ထုတ်ပြီး ကျန် ၂ ခုကို နှိုင်းယှဉ်ပါ။
